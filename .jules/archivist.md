## 2024-10-26 - Shell Script Docblocks
**Learning:** Shell functions often lack documentation, making their parameters and behaviors ambiguous.
**Action:** Apply structured JSDoc-style docblocks prefixed with `# ` to shell functions to maintain consistent inline clarity.


## 2024-10-28 - Python Sphinx Docstrings
**Learning:** Python functions use varying documentation formats, causing inconsistencies.
**Action:** Apply structured Sphinx-style docstrings using :param:, :returns:, and :raises: tags for Python files instead of JSDoc to maintain consistent and idiomatic inline clarity.
